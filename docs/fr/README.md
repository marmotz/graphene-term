# Guide d'utilisation de Graphene Term

Graphene Term est un émulateur de terminal accéléré par le GPU, pour Linux et macOS. Le
programme s'appelle `graphene`.

Les libellés de l'interface cités dans ce guide (menus, palette de commandes,
paramètres) sont ceux de l'interface en français : voir le paramètre `language` dans
[Configuration](configuration.md#général).

## Pour commencer

1. [Installation](installation.md) : paquets pour Linux et macOS, ou compilation depuis
   les sources.
2. [Premiers pas](getting-started.md) : le premier lancement et cinq choses à essayer.

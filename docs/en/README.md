# Graphene Term user guide

Graphene Term is a GPU-accelerated terminal emulator for Linux and macOS. The program
is called `graphene`.

## Start here

1. [Installation](installation.md): packages for Linux and macOS, or build from source.
2. [Getting started](getting-started.md): the first launch and five things to try.
